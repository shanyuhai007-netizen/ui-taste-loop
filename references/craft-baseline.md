# Craft Baseline——build 端质量前置基线

定位：critic 循环修 craft 细节是最贵的路径（每轮一个 fresh subagent），而实测中 critic 反复挑的正是间距、字阶、色彩层次这类确定性问题（见 [docs/evaluation-2026-11-18.md](../docs/evaluation-2026-11-18.md)）。这类问题必须在 build 时一次做对。本文件自带全部规则，不依赖外部 skill。

## 方向卡（Phase 1 产物规范）

「现代简约风」「高级感」这类空话方向无法评审。Phase 1 发散的 4 个方向，每个必须以一张字段齐全的方向卡交付：

| 字段 | 要求 | 反例 |
|---|---|---|
| 方向名 | 一个有记忆点的词，不是风格分类词 | ❌「简约现代」 |
| 灵感源 | 一句话，具体到实物、作品或场景 | ❌「高级感」✅「瑞士地形图等高线的分层标注」 |
| 配色素描 | 3-5 个 hex：底色 / 前景 / 次要文本 / 强调 | ❌「蓝紫渐变主色」 |
| 字体配对 | display 与 body 的具体字族名，真实可用 | ❌「无衬线字体」 |
| 布局隐喻 | 一句话讲清空间结构 | ❌「卡片式布局」✅「左窄工具轨 + 右宽画布，像暗房接触印样」 |
| 敢在哪 | 这个方向最大胆的一个决定 | —— |

人按卡挑方向。卡与卡的差异必须能从字段直接看出来；两张卡字段雷同 = 发散失败，重出。

## Token 契约（选定方向后、写第一行代码前）

方向卡选定后先展开成完整 token 契约，实现只能取契约内的值。六段：

1. **color**：4-6 个命名色（bg / fg / muted / border / accent / status），逐色标注用途。对比度底线：正文 ≥4.5:1，大字（≥24px，或 ≥18.66px 加粗）≥3:1——不达标换色，不降标准。
2. **type**：字族与角色（至多两族，两族需明显区分）；完整字阶（如 12/14/16/20/24/32/48，比例固定）；每级行高；字重限 2-3 档。正文行长 <80 字符，衬线可略宽、行高略松。
3. **spacing**：全部间距取自一个 4px 基数阶（4/8/12/16/24/32/48/64），一档枚举，禁止阶外魔法数。
4. **layout**：圆角限 2-3 档并注明每档用途；阴影限 2-3 档；边框规则（1px 与 hairline 的用途区分）；对齐基准（左对齐 / 居中的选择与理由）。
5. **motion**：时长档位（如 120/200/320ms）+ easing 档位 2-3 条（注明各档语义）；只动 transform 与 opacity；非用户触发的动效至多一个编排时刻。
6. **principles**：3-5 条本项目独有原则，每条从方向卡推导，不写通用格言。

契约存进票内。critic 循环中每次修改后对照自查；契约本身要改时，同步改全部已实现处，不留漂移。

## Craft 检查单（确定性自查）

build 完成后、每轮 critic 修改落地后各过一遍。命中即修，不让这类问题流入 critic：

- [ ] 字号、间距、颜色全部取自 token 契约阶内值（grep 核对阶外值）
- [ ] 对齐线连续：同一列的左边缘在整页上是一条线
- [ ] 图标尺寸统一（单一像素尺寸，或两档并明确各自用途）
- [ ] 数字表格列使用 tabular-nums
- [ ] 键盘焦点可见、reduced motion 有降级
- [ ] 文本与背景对比达契约底线
- [ ] 同层级组件的圆角、阴影、内边距一致
- [ ] 375px 断点下无横向滚动、无元素堆叠出屏
